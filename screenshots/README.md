## To add them

1. Open the [live Power BI dashboard](https://app.powerbi.com/view?r=eyJrIjoiMzA5NTFjOTctNjBhZS00Y2ZlLWIwNDMtNzhmZDY1OTVmNzNhIiwidCI6IjdiYWEzZDBkLTdmZjYtNDFkNS05NmQ3LTg0NzM3NzY0NjAyMSJ9).
2. Capture the main overview page and the role/age/business-unit breakdown views.
3. Save them here with descriptive filenames, for example:
   - `overview.png`
   - `absenteeism-by-role.png`
   - `workforce-demographics.png`
   - `absence-hours-distribution.png`
4. Reference them from the main `README.md` under **Dashboard preview** once added.
